## <img src="https://api.iconify.design/lucide:gem.svg?color=%232ECC71" width="24" align="absmiddle" /> Flagship Build

### [Symbiote](https://github.com/Cheru864/symbiote)

An attentive coding companion that watches terminal and git activity, learns your working rhythm, and flags friction or fatigue before you notice it yourself.

* <img src="https://api.iconify.design/lucide:brain.svg?color=%232ECC71" width="16" align="absmiddle" /> **Terminal Awareness**: A PTY wrapper that forwards shell sessions while extracting commands, durations, exit codes, and keystroke rhythm. Tools like `vim`, `tmux`, `fzf`, `htop`, `helix`, and `emacs` run unchanged; sensitive inputs are detected and withheld.
* <img src="https://api.iconify.design/lucide:activity.svg?color=%232ECC71" width="16" align="absmiddle" /> **Signal Bus**: A debounced, priority-aware event bus unifying streams for:
  * <img src="https://api.iconify.design/lucide:folder.svg?color=%232ECC71" width="14" align="absmiddle" /> **File changes**
  * <img src="https://api.iconify.design/lucide:git-merge.svg?color=%232ECC71" width="14" align="absmiddle" /> **Git signals**
  * <img src="https://api.iconify.design/lucide:terminal-square.svg?color=%232ECC71" width="14" align="absmiddle" /> **Terminal events**
* <img src="https://api.iconify.design/lucide:scale.svg?color=%232ECC71" width="16" align="absmiddle" /> **Self-Regulation**: A six-dimensional state machine tracking health, complexity load, stagnation, friction, flow, and concern, with burnout detection modeled against a learned keystroke baseline.
* <img src="https://api.iconify.design/lucide:plug.svg?color=%232ECC71" width="16" align="absmiddle" /> **Plugins**: WASM sandboxing (`wasm32-wasip2`) running under a default-deny capability manifest, fuel-bounded execution, and full audit logging.
* <img src="https://api.iconify.design/lucide:monitor.svg?color=%232ECC71" width="16" align="absmiddle" /> **TUI**: `symbiote-visualize` renders live system state straight from the daemon database.
