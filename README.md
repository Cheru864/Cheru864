## Flagship Build

### [Symbiote](https://github.com/Cheru864/symbiote)

An attentive coding companion that watches terminal and git activity, learns your working rhythm, and flags friction or fatigue before you notice it yourself.

* :brain: **Terminal Awareness**: A PTY wrapper that forwards shell sessions while extracting commands, durations, exit codes, and keystroke rhythm. Tools like `vim`, `tmux`, `fzf`, `htop`, `helix`, and `emacs` run unchanged; sensitive inputs like passwords and `sudo` prompts are detected and withheld from logs.
* :bar_chart: **Signal Bus**: A debounced, priority-aware event bus unifying streams for:
  * :file_folder: **File changes**
  * :twisted_right_arrows: **Git signals**
  * :keyboard: **Terminal events**
* :scales: **Self-Regulation**: A six-dimensional state machine tracking health, complexity load, stagnation, friction, flow, and concern, with burnout detection modeled against a learned keystroke baseline.
* :electric_plug: **Plugins**: WASM sandboxing (`wasm32-wasip2`) running under a default-deny capability manifest, fuel-bounded execution, and full audit logging.
* :desktop_computer: **TUI**: `symbiote-visualize` renders live system state straight from the daemon database.
