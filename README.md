## 📌 Featured Project

<p align="center">
  <a href="https://github.com/Cheru864/backstop">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=Cheru864&repo=backstop&theme=github_dark&hide_border=true" />
  </a>
</p>

<p align="center">
  <strong>Backstop</strong> is a continuous guardian for vibe‑coded apps.<br>
  It monitors <strong>security, uptime, cost spikes, and visual regressions</strong> — so you know your app is broken before your customers do.
</p>

<p align="center">
  🔒 <strong>Security Scanning</strong> — Live URL scans, secret detection, stack‑aware misconfig checks<br>
  📡 <strong>Global Uptime</strong> — Multi‑region synthetic checks with latency tracking<br>
  💰 <strong>Cost Anomalies</strong> — Flags runaway API usage before the invoice hits<br>
  🎯 <strong>Visual Regression</strong> — Playwright DOM & screenshot diffs on every deploy
</p>
