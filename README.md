## Featured Project — Symbiote

<p align="center">
  <strong>An attentive coding companion.</strong><br />
  Observes terminal and git activity, learns working rhythm, and surfaces early signals of fatigue or friction.
</p>

<table>
  <tr>
    <td width="50%">
      <strong>Terminal Awareness</strong><br />
      PTY wrapper that forwards the shell session while extracting events — commands, durations, exit codes, pipeline status, keystroke rhythm.<br /><br />
      <em>vim, tmux, fzf, htop, helix, and emacs work unchanged. Sensitive input such as passwords and sudo prompts is detected and withheld, never logged.</em>
    </td>
    <td width="50%">
      <strong>Signal Bus</strong><br />
      Medium-frequency event bus with debounce and priority handling.<br /><br />
      File changes via notify · Git signals — commits, branch switches, project root · Terminal events — commands, durations, keystrokes
    </td>
  </tr>
  <tr>
    <td width="50%">
      <strong>Self-Regulation</strong><br />
      Six-dimensional state machine tracking health, complexity load, stagnation, friction, flow, and concern.<br /><br />
      <em>Burnout detection classifies keystroke rhythm against a learned baseline.</em>
    </td>
    <td width="50%">
      <strong>Plugins</strong><br />
      Sandboxed WASM plugins (wasm32-wasip2) with:<br />
      Default-deny capability manifest · Fuel-bounded execution · Audit log
    </td>
  </tr>
  <tr>
    <td width="50%">
      <strong>Semantic Layer (optional)</strong><br />
      llama.cpp-backed error clustering and commit-message drafting, guarded behind a circuit breaker.
    </td>
    <td width="50%">
      <strong>TUI</strong><br />
      <code>symbiote-visualize</code> renders the organism's state directly from the daemon database.
    </td>
  </tr>
</table>
